# Integration Checklist

URL: https://www.digia.tech/docs/developer/integration-checklist

This page lists the rules that a correct Digia Engage integration satisfies. Use it to review an integration by hand, or let a coding agent run it with the `setup-digia-engage` skill.

Each rule has:

- **ID** — a stable name, for example `RN-03` .
- **Severity** — `fail` breaks campaigns. `warn` degrades them.
- **CEP** — the CEP setups the rule applies to. `all` means every setup. `digia` meansDigia as your CEP , with no CEP plugin.
- **Detect** — what to look for in the app source.
- **Fix** — the change that satisfies the rule.
info
Read the current package versions from the platform pages. This page does not pin versions.
